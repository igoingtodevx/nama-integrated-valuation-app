Worum geht es in der 35-Punkte-Aufgabe?

Die Aufgabe fordert die integrierte Unternehmensbewertung (Integrated Valuation) im Rahmen einer M&A-Transaktion. Ein Käufer prüft die Übernahme eines Zielunternehmens.

Es müssen 3 Dimensionen berechnet werden:

  • 1. Financial Value (FV): Der rein finanzielle Wert auf Basis zukünftiger Free Cash Flows (FCF).
  • 2. Environmental Value (EV): Der finanzielle Barwert der durch $CO_2$ verursachten Umweltschadenkosten ( True Price Index).
  • 3. Integrated Value (IV): Der gesellschaftliche Gesamtwert der Transaktion.
$$\text{Integrated Value} = \text{Financial Value} - \text{Environmental Value} + \text{Social Value}$$

Das unumstößliche 5-Schritte-Schema

1

Effektiven Steuersatz ($s_{eff}$) berechnen

s_eff = s_ks * (1 + s_z) + s_gew

Achtung: SolZ ($s_z = 5{,}5\%$) fällt NUR auf die KSt ($s_{ks} = 15\%$) an!

2

EBIT & Free Cash Flows (FCF) berechnen

EBIT = EBITDA - Abschreibungen
FCF = NOPAT = EBIT * (1 - s_eff)

Da Investitionen = Abschreibungen, entspricht FCF exakt dem NOPAT.

3

Financial Value (Unternehmenswert) ermitteln

Diskontierung der Cashflows bis Jahr $n-1$ + Ewige Rente ab Jahr $n$ diskontiert auf heute ($t=0$).

4

Environmental Value ($CO_2$-Schaden) ermitteln

Schaden_t = CO2_Mio_Tonnen_t * Schattenpreis_t

Schattenkosten diskontieren mit demselben $r_{wacc}$.

5

Integrated Value & Interpretation

Integrated Value = Financial Value - Environmental Value (+ Social Value)

⚠️ Die 5 tödlichen Klausur-Fallen & Edge Cases

Hier verlieren Studierende in der Klausur die meisten Punkte. Lerne diese 5 Fallen auswendig!

Falle 1

Falsche SolZ-Berechnung beim Steuersatz

Falsch: $s_{eff} = (15\% + 14\%) \times 1{,}055 = 30{,}595\%$ (Falsch! SolZ fällt NICHT auf die Gewerbesteuer an!)

Richtig: $s_{eff} = 15\% \times 1{,}055 + 14\% = 15{,}825\% + 14\% = \mathbf{29{,}825\%}$

Falle 2

Diskontierungsfehler bei der Ewigen Rente

Die Ewige Rente $\frac{FCF_{\text{ewig}}}{r_{wacc}}$ ergibt den Wert zum Zeitpunkt $t = n-1$ (z.B. Ende 2025). Du musst diesen Wert zusätzlich um $(1 + r_{wacc})^{n-1}$ auf den Zeitpunkt $t=0$ diskontieren!

$$\text{Barwert}_{\text{ewig}} = \frac{FCF_{\text{ewig}}}{r_{wacc} \times (1 + r_{wacc})^{n-1}}$$
Falle 3

Vorzeichen-Falle beim Integrated Value

Wichtig: Der Environmental Value ist ein Schaden ($\rightarrow$ abziehen). Ein Social Value (z.B. Lebensqualität/Quality Life Years) ist ein Nutzen ($\rightarrow$ hinzurechnen)!

Integrated Value = Financial Value - Environmental Value + Social Value
Falle 4

Fremdkapitalzinsen NICHT abziehen

Im Aufgabentext steht oft das Fremdkapital (z.B. $6.500 \text{ TE}$ oder $8.000 \text{ TE}$) und die Fremdkapitalkosten $r_{fk} = 4\%$.

Falle: Ziehe Fremdkapitalzinsen NICHT vom EBIT ab! Der WACC-Ansatz ist ein Bruttoansatz (Entity-Ansatz). Die Fremdkapitalkosten stecken bereits im WACC ($r_{wacc}$).

Falle 5

Einheiten & Runden (4 Nachkommastellen)

Im Deckblatt steht ausdrücklich: "Rechnen Sie auf 4 Nachkommastellen."

Achte auf Einheiten: $CO_2$ ist in Mio. Tonnen angegeben, Schattenpreise in Euro/Tonne. Mio. Tonnen $\times$ €/Tonne = Mio. Euro!
